# SHIFT — Neon Logic

Offline Android puzzle game. Source code is in `app/src/main/assets/index.html`, hosted inside a native Android WebView.

## Build APK

Open **Actions → Build SHIFT Android APK** and run the workflow, or push to `main`. Download the `SHIFT-Neon-Logic-debug-APK` artifact from the successful run. The APK is a debug build for testing, not a signed Play Store release.
